# VVCHAIN FULL · V1 ODD-EXP

This branch is a complete VVChain build. Only the ANALOG colour algorithm differs between the three full branches; EQ, OTT, TYPE-A, DE-ESSER, MIX, solo, limiter, latency compensation and UI remain from the verified VVChain main line.

## ANALOG guarantees
- Memoryless sample-domain transfer.
- No added delay, look-ahead, feedback or envelope state.
- No DC follower in the ANALOG stage.
- No cross-channel state sharing.
- Intended to be tested together with the complete chain.
